**Вариант 1: «Приветствие с локализацией»** — персонализированный API,
который возвращает приветствие на русском или английском языке в
зависимости от query-параметра.

- Инициализирован npm-проект, установлен Express.
- Написан HTTP-сервер на Express (`app.js`), слушает порт 3000.
- Реализовано логирование каждого запроса в консоль (middleware).
- Настроена раздача статики из папки `public/` через `express.static`.
- Реализованы маршруты:
  - `GET /` — главная страница (отдаёт `index.html`);
  - `GET /about` — страница «О сайте» (отдаёт `about.html`);
  - `GET /api/greet/:name` — JSON-приветствие с параметрами.
- Добавлена валидация параметра `:name` (только буквы, 1–50 символов).
- Добавлен обработчик 404 для неизвестных маршрутов.
- Реализована обработка query-параметра `?lang=ru|en` (по умолчанию `en`).

Клиент (PWA)

- Создан `manifest.json` с именем, цветами, `display: standalone` и
  иконками 192×192 и 512×512.
- Манифест подключён в HTML через `<link rel="manifest">`.
- Написан Service Worker (`sw.js`):
  - прекеширует статику при `install`;
  - удаляет старые кеши при `activate`;
  - использует cache-first для статики и network-first для `/api/*`
    с JSON-fallback при офлайне;
- Service Worker зарегистрирован в `index.html` после загрузки страницы.
- Добавлена кнопка «Приветствовать» вызывает API через `fetch` и показывает результат на странице(`app.js`)

Запуск

npm install
npm start
